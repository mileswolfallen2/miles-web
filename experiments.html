THE HISTORY
OF THE INTERNET

From four computers to billions of devices — a cinematic timeline of the network that changed how we live, work, and think.

Scroll to explore
1950s — 1960s

The Idea

The Cold War drove the need for networks that could survive nuclear attack. J.C.R. Licklider imagined an "Intergalactic Computer Network." Packet switching was born — splitting data into small packets that find their own route.

Licklider Intergalactic Computer Network
Packet Switching Split data → find routes → reassemble
Cold War Survivable military networks
Baran & Davies Independently invented packet switching
1969

ARPANET

ARPANET became the first real packet-switched network. Four computers linked UCLA, Stanford, UCSB, and Utah. The first message ever sent was supposed to be "LOGIN" — but the system crashed after "LO."

ARPANET INITIALIZATION v1.0
> CONNECTING TO UCLA...
> CONNECTING TO SRI...
> CONNECTING TO UCSB...
> CONNECTING TO UTAH...
> SENDING: LOG_
! SYSTEM CRASH - SEGMENTATION FAULT
First message ever: "LO"
_
1970s

Building the Foundation

Email, file transfer, and remote login made networks useful beyond research. Vint Cerf and Bob Kahn then defined TCP/IP, the language that lets different networks speak to each other. The "internetwork" was born.

TCP/IP — connecting networks across the globe
January 1, 1983

The Birthday of the Internet

ARPANET officially switched to TCP/IP. Every modern internet connection still uses descendants of this protocol today. This is the day the Internet truly became the Internet.

01.01.83
ARPANET → TCP/IP → The Internet
The 1980s

Command Line Days

The early Internet lived in universities and labs. There were no websites yet — only email, FTP, bulletin boards, and command-line interfaces. Users typed commands into glowing green terminal screens.

[user@localhost ~]$
1980s

Domain Names

Instead of memorizing IP numbers like 192.168.1.45, people could type easy names like example.com. The Domain Name System (DNS) became the web's directory service, translating names into addresses. .com, .org, .edu, and .gov became familiar online neighborhoods.

1989 — 1991

The World Wide Web

Tim Berners-Lee invented HTML, HTTP, URLs, and the first browser. The Web is a service on top of the Internet, but its launch made linked documents easy to read and share. Everything changed.

World Wide Web

The WorldWideWeb (W3) is a wide-area hypermedia information retrieval initiative aiming to give universal access to a large universe of documents.

Everything there is online about W3 is linked directly or indirectly to this document.

This is the first website ever — recreated here as it appeared in 1991.

Tim Berners-Lee, CERN
Recreation of info.cern.ch — the first web page in history
Early 1990s

The First Websites

Black text, blue links, white background. No images, no CSS, no JavaScript — just HTML. Simple and raw, these first homepages proved that anyone could publish on the Web.

1990s

Browsers Arrive

Mosaic made the Web visual. Netscape Navigator turned browsing into an everyday activity. Suddenly anyone could explore the Web — not just researchers with command lines.

🌐

Mosaic (1993)

The first popular graphical browser. Made images appear inline with text instead of in a separate window. Changed everything.

🦊

Netscape Navigator (1994)

The dominant browser of the 90s. 90% market share at its peak. Spawned JavaScript and SSL. Legendary.

The Dot-com Boom

Businesses realized the Internet could make money. Amazon, Yahoo, eBay launched. .com was the hottest thing you could put after a name. Money flowed like water.
