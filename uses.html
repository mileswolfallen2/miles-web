What I Use

The hardware, software, and tools I reach for every day. No sponsors, no affiliate links — just what actually works for me.

Hardware

MacBook Air M4 (2024)

The 13-inch MacBook Air runs macOS 27.3 on Apple M4 with 16 GB of unified memory, a 256 GB SSD, and a 2940×1912 built-in Liquid Retina display. It stays completely fanless while handling VS Code, terminal sessions, Docker, browsers, and development previews. This is my primary workstation.

HP ProBook 440 G7

My mobile Linux rig runs Omarchy 4.5.0 on Intel Core i5-10210U. It has 8 GB of RAM, an approximately 236 GB disk, a 1366×768 display, and enough speed for writing, development, system experiments, and work away from the Mac. It is the keyboard-first environment I take with me.

Google Pixel 8A

Stock Google Android. No bloat, no nonsense. Does what a phone should do and stays out of the way.

Steam Deck

My portable testing rig. I use it for game dev testing, tinkering with Linux, and sometimes actual gaming. Surprisingly capable for a handheld.

Software

Omarchy

My preferred Linux setup on the HP ProBook. Omarchy gives me a polished, opinionated environment right away while still leaving plenty of room to install tools and make the system my own. It is the setup I reach for when I want to stay focused and move quickly.

VS Code

My main editor. Cursor's AI features are nice, but VS Code with the right extensions is unbeatable. I run the GitHub Copilot extension, ESLint, Prettier, and a handful of theme and icon packs. My config is mostly default — I don't spend time tweaking my editor, I spend time writing code.

opencode

The CLI tool I use for AI-assisted development. It runs in the terminal, integrates with my workflow, and doesn't try to replace my editor. I use it for refactoring, code review, and bouncing off ideas when I'm stuck.

Brave

My main browser. Fast, Chromium-based, and the built-in ad blocking means I don't need extensions for the basics. Shields Up mode is the default everywhere. I use it for everything — dev work, browsing, media, you name it.

Firefox

I keep Firefox around for testing and for a few extensions that work better in its ecosystem. The container tabs are great for separating work/personal stuff when I need it. Still respect what Mozilla does, just not my daily driver anymore.

Terminal

Ghostty. Fast, native-style terminal that looks good out of the box. GPU-accelerated, no config nonsense. I keep my prompt clean with a few aliases and git integration — spent years customizing and realized I was just procrastinating.

Linux

Omarchy on the HP ProBook is my current mobile Linux setup. The rest of my Linux experience has been useful too: Debian with KDE Plasma was solid and predictable, while Arch with Hyprland showed me how much I enjoy a tiling, keyboard-driven workflow. I use Linux to understand more about the machines I work on and to have another environment for development.

macOS

The MacBook Air is my primary desktop-class workstation. I use macOS for its polished ecosystem, battery life, and quiet performance, and I keep the setup straightforward. Terminal tools, VS Code, browsers, Git, Docker, and local servers cover most of my day-to-day work.

Other Tools

  • GitHub: Where everything lives. 147+ repos and counting.
  • Git: For version control, branches, commits, pull requests, and keeping experiments recoverable.
  • Docker: Useful for reproducible local environments and services that are easier to keep isolated.
  • Cloudflare: DNS, domain management, and some worker scripts.
  • Blender: For 3D modeling when I need it.
  • Unity / Unreal: Game engines I dip into for prototypes.
The best tool is the one you don't notice using.
